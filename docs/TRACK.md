## Hacki — General judging criteria (optimize demo for these)

From [Hacki Aleph 2026](https://hacki.crecimiento.build/h/aleph-hackathon-2026):

| Criterion | What judges ask | Casandra demo proof |
|---|---|---|
| **Technicality** | Hard problem? Solid engineering? | MCP stdio tools + shared `market-core` + explainable risk + optional on-chain registry |
| **Originality** | Unique? Real pain? | Agents hallucinate prices/risk → Casandra returns timestamped JSON |
| **UI/UX/DX** | Usable for users *and* developers? | Web gauge for judges + Cursor MCP config in README |
| **Practicality** | Real-world use? Feasible? | Portfolio state + risk for investment agents; CoinGecko live |
| **Presentation** | Clear pitch + demo? | ≤3 min video: problem → gauge → MCP tool → contract address → disclaimer |
